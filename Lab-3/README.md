
# Lab 3 - Component Modelling and Architectural Pattern Selection

## Project
Hyperlocal Courier Dispatch & Tracking Engine

## Objective
To design a UML Component Diagram and select a suitable software architecture for the system.

## Selected Architecture
Microservices Architecture

## Components
- Customer App
- Order Service
- Dispatch Service
- Courier Service
- Tracking Service
- Notification Service
- Operational Database

## Architecture Justification
Microservices Architecture was selected because it provides:

1. Independent Scalability
2. Modularity and Fault Isolation
3. Improved Security
4. Better Performance
5. Independent Maintenance and Deployment

## Deliverable
Component Diagram and Architecture Justification PDF.
